# Accessibility Statement

This site targets **WCAG 2.1 Level AA** conformance. We aim to make the CachyOS on MacBook Air 2020 documentation accessible to all users.

## Accessibility Features

- **Keyboard navigation** — All interactive elements are reachable and operable via keyboard
- **Skip to content** — A skip link is provided to bypass repeated navigation
- **Focus indicators** — Visible `:focus-visible` outlines on all focusable elements
- **Reduced motion** — Animations and transitions are disabled when `prefers-reduced-motion` is enabled
- **Semantic HTML** — Proper heading hierarchy, landmark regions, and ARIA attributes
- **Dark mode contrast** — The Catppuccin Mocha colour scheme passes WCAG AA contrast ratios
- **Responsive layout** — Content reflows for viewport widths down to 320px
- **Alt text** — All images include descriptive alternative text

## Known Limitations

- Some code blocks may require horizontal scrolling on narrow viewports
- The search modal relies on JavaScript; content is still accessible via the sidebar navigation

## Feedback

If you encounter accessibility barriers on this site, please [open an issue on GitHub](https://github.com/sebastienrousseau/cachyos-macbook-intel-2020/issues) with the subject line "Accessibility" and a description of the problem. We will respond within 7 days.
